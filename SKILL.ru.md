# MeshGate — навык «шлюз ассетов»

Ты доводишь один входной ассет до канонического GLB по **контракту ассета** (`docs/asset-contract.ru.md`) и кладёшь его в нужный рантайм. Всё идёт через `meshgate.py` в корне репозитория; не подбирай флаги экспортёра и настройки импорта движков вручную.

Ступица и спицы: источники (сейчас Blender, дальше Maya) → **канонический GLB + валидатор** → цели (web, Unity, Godot, Unreal). FBX — запасной путь рядом с GLB для редакторов движков и ригов, никогда не вместо него.

## 0. Перед началом

```bash
python3 meshgate.py doctor
```

Запомни, какие инструменты есть. Blender нужен для экспорта; Unity 6000.0+ и Godot 4.4+ — только для проверок соответствующих движков. Если инструмента нет, скажи об этом и делай то, что возможно, — никогда не заявляй проверку движка, которую не смог запустить. Для проверки Unreal установка не нужна: `meshgate.py check unreal` сверяет плагин с Python API UE 5.4–5.6; живого прогона в редакторе ещё не было.

Спрашивай пользователя только то, что меняет работу: какие **цели** (по умолчанию web + движок, который он назвал) и, для персонажей, нужен ли **Humanoid-ретаргет** (Unity Mecanim / UE Mannequin).

## 1. Классифицируй вход

| Вход | Путь |
|---|---|
| `.blend` с пропсом/сценой | §2 → §3 |
| GLB/glTF со стороны | сразу §3 (проверка), чинить в Blender только если валидатор ругается |
| FBX со стороны | импорт в Blender, сохранить `.blend`, затем §2 → §3 |
| Риггованный гуманоид (Avaturn, Mixamo, Rigify, UE, VRoid…) | `python3 meshgate.py character in.glb --out out.glb` → §3 |
| Текстовый промпт (предмет, механизм, часть здания) | `python3 meshgate.py gen "<описание>" [--size M] [--style …]` спрашивает ИИ-CLI пользователя и выдаёт по проверенному файлу на уровень. Ты сам ИИ: можешь вместо этого написать `build(mg)` на наборе (`python3 meshgate.py gen "<описание>" --prompt-only` печатает API и правила) и запустить его через `gen --code file.py --name N`. Прочитай отчёт и исправь то, что в нём перечислено. См. `docs/generation.ru.md` |
| Картинка предмета | `python3 meshgate.py gen --image pic.png [--size M]`: нейросетка (TripoSR локально после `gen --setup triposr` или Meshy/Tripo/fal с ключом пользователя), доведённая по уровням. Для стилизованных предметов добавь `--engine kit` и сам напиши код сборки, глядя на картинку |
| Сетка со стороны (Sketchfab, сайт генератора) | `python3 meshgate.py gen --mesh file.glb --size M`: нормализация, выпрямление, упрощение по уровням, развёртка, запекание |
| Персонаж по тексту или картинке | пока не поддерживается (roadmap v0.6.2). Скажи об этом; предложи параметрического человека (MakeHuman/MPFB) или внешний генератор, затем `meshgate.py character` на результате |

Чужие ассеты не клади в git: только в `samples/_local/` (игнорируется).

## 2. Подготовка в Blender (только то, что требует контракт)

Если пользователь работает в интерфейсе Blender, всё это делает аддон MeshGate (N → MeshGate, `sources/blender/README.ru.md`) кнопками Проверить / Исправить / Экспорт — поставь его командой `python3 meshgate.py install-blender` (попроси сначала закрыть Blender). Без интерфейса те же правила и исправления запускаются через `export_meshgate.py --check --fix`.


Проверяй и чини в исходной сцене небольшим Python-скриптом Blender (`-b file.blend -P fix.py`), а не правкой экспортированных файлов:

- **Метры, 1 юнит = 1 м.** Реальные размеры: сундук ~0.8 м, человек ~1.75 м.
- **Применённый масштаб.** Масштаб 1 у мешей (экспортёр применяет его сам, если масштаб не анимирован).
- **Осмысленный origin.** Предметы на полу — origin в основании (после экспорта min Y = 0). Шарниры и вращающиеся части — origin в точке вращения (крышка на петле, ротор на оси).
- **Имена.** ASCII без пробелов (`crate_lid`, `body_metal`). Во всех движках код обращается к нодам по имени.
- **Только PBR.** Principled BSDF с текстурами или константами. Процедурные ноды сначала запечь в текстуры.
- **UV на каждом меше** с текстурой или под лайтмап.
- **Анимации — NLA-стрипами**, один стрип на клип, с именем (`idle`, `lid_open`). Свободные действия тоже экспортируются, но NLA держит одинаковые имена клипов в GLB и FBX.
- **Вспомогательное скрыто от рендера** (операнды boolean, направляющие): `hide_render = True` — экспортёр их пропускает.
- **Персонажи:** кости по Unity Humanoid (`Hips, Spine, Chest, Neck, Head, Left/RightShoulder, Left/RightUpperArm, Left/RightLowerArm, Left/RightHand, Left/RightUpperLeg, Left/RightLowerLeg, Left/RightFoot, Left/RightToes`), rest-поза — T-поза, не больше 4 весов на вершину. Имена Mixamo/Rigify/UE понимает `meshgate.py character`.

## 3. Экспорт и проверка

```bash
python3 meshgate.py export scene.blend --out build/asset.glb --fbx      # GLB + FBX, валидатор запускается сам
python3 meshgate.py validate build/asset.glb build/asset.fbx --strict  # повторная проверка; --json для машин
```

`--draco` добавляй только для чисто веб-доставки (Godot и Unreal его не декодируют). Готово, когда валидатор со `--strict` возвращает 0. Каждое предупреждение — правка в исходнике и повторный экспорт:

| Валидатор пишет | Правка в Blender |
|---|---|
| габариты < 1 см / > 100 м | не те единицы: масштабировать сцену в метры, применить масштаб |
| низ ассета ниже origin | перенести origin в основание (`origin_set` на курсор в min Z) |
| масштаб ≠ 1 у мешей | применить масштаб (`transform_apply(scale=True)`) или убрать анимацию масштаба |
| нет UV (TEXCOORD_0) | развернуть (`uv.smart_project` / `cylinder_project`) |
| нет нормалей / не треугольники | триангуляция при экспорте (по умолчанию), пересчитать нормали |
| материалы без PBR | пересобрать на Principled BSDF, запечь процедурные ноды |
| текстура не степень двойки / > 4096 | привести к 1024/2048 |
| внешняя текстура | упаковать изображения в .blend (`image.pack()`) |
| имена нод/материалов с пробелами или не-латиницей | переименовать |
| вершины без весов / сумма ≠ 1 | нормализовать веса, отдать «потерянные» вершины ближайшей кости |
| скелет похож на гуманоида, но не хватает костей | переименовать по Unity Humanoid (см. §2) или `meshgate.py character` |
| неизвестное/обязательное расширение | отключить эту фичу материала или принять её только для целей, которые её понимают |

Затем посмотри глазами:

```bash
python3 meshgate.py serve --glb build/asset.glb
```

Во вьюере проверь паспорт (габариты, UV, кости), проиграй каждый клип, `S` — скелет, `U` — UV-шахматка. Если есть браузерный инструмент, сделай скриншот и посмотри сам, а не проси пользователя.

**Уровни качества.** Спроси, какие устройства важны. Экспортируй варианты уровней с `--profiles mobile-low,mobile-mid,mobile-high` (канонический GLB — PC-версия) и проверяй через `validate_glb.py --profile all`; если геометрию генерируешь сам, строй под бюджет уровня, а не децимируй (см. `docs/quality-tiers.ru.md`).

## 4. Доставка в цели

**Web.** Встроить `targets/web/meshgate-viewer.js` (`createViewer(el).load(url)`) — см. `targets/web/README.ru.md`.

**Unity 6.** Добавить пакет `https://github.com/MaverickGH/meshgate.git?path=targets/unity/com.meshgate.unity` (или `file:`-путь). Дальше:
- Рантайм: GLB в `Assets/StreamingAssets/`, GameObject с `MeshGateAsset` (source = имя файла). В режиме редактора он **пустой** — грузится по Play.
- Редактор: GLB или FBX в `Assets/` (GLB импортирует glTFast, FBX — сам Unity). Для FBX извлечь текстуры (`ModelImporter.ExtractTextures`), иначе материалы серые; `MeshGateFbxMaterials` переводит Blender-Phong в Standard/URP Lit.
- Персонажи: FBX → `animationType = Human`, аватар из модели. Humanoid-клипы потом ретаргетятся на любого другого Humanoid.
- FBX-экземпляры с анимацией ставить **под пустого родителя**: Blender-FBX ключует корневой объект, и Animator сбросит его позицию.
- `MeshGate → Build Demo Scene` собирает референсную сцену из `samples/`.

**Godot 4.** Скопировать `targets/godot/MeshGateDemo/addons/meshgate` в проект, включить плагин, добавить `MeshGateAsset` с `source`. Редакторский импорт `.glb` — родной. Draco нет.

**Unreal 5.** Экспорт с `--targets unreal` (плюс прокси коллизий через «Добавить коллизию» в аддоне → `<name>.unreal.fbx` с `UCX_`). Скопировать `targets/unreal/MeshGate` в `Plugins/`, затем `meshgate_import.import_samples(dir)` или `import_file(path, '/Game/...')`: GLB — через Interchange с пайплайном MeshGate, FBX — через Interchange (5.5+) или старый импортёр; персонажи — Skeletal Mesh, IK Retargeter на Mannequin (`meshgate_retarget.ru.md`). Скажи пользователю, что плагин сверен с API, но в живом редакторе ещё не запускался.

## 5. Проверка в движках

```bash
python3 meshgate.py check web
python3 meshgate.py check unity            # BuildAll + PlayMode-тесты (--render — ещё и PNG сцены)
python3 meshgate.py check godot            # headless-проверка контракта
python3 meshgate.py check all
```

Проверки идут по `samples/`. Новый ассет пользователя добавь рядом с примерами (или в списки тестов `targets/unity/MeshGateSample/Assets/Tests` и `targets/godot/MeshGateDemo/tests/test_meshgate.gd`) с ожидаемыми именами нод, клипами и габаритами — проверка, которая не называет ассет, ничего о нём не доказывает.

Если Unity-проект открыт в редакторе, batch mode его не возьмёт; управляй открытым редактором через Unity MCP-мост, если он подключён, иначе попроси пользователя закрыть проект.

## 6. Отчёт

Сообщи пользователю по порядку: что теперь работает и где (пути к файлам, сцена), вердикт валидатора, какие проверки движков запускались и с каким результатом, что не удалось проверить (нет инструмента, Unreal). Числа — в короткую таблицу. Не заявляй, что цель работает, без проверки или скриншота.

## Грабли, на которые мы уже наступили

- Объекты с рантайм-загрузкой невидимы до Play — всё, что пользователь должен видеть в сцене, ставь редакторским импортом.
- Blender-FBX: встроенные текстуры ссылаются на несуществующую папку `*.fbm`; Unity нужно их извлечь; roughness-карты и прозрачность теряются.
- Клип на несколько объектов в FBX превращается в take на каждый объект (в GLB это один клип).
- `SkinnedMeshRenderer.bounds` — оценка от корневой кости; габариты персонажа мерь по bind-позе меша.
- Draco работает только в Three.js, glTFast и (с пакетами) Unity.
- «Фейковый null» Unity: `GetComponent<T>() ?? AddComponent<T>()` — ошибка; используй `TryGetComponent`.
- Скрипты Blender: присваивание `obj.parent` из Python сбрасывает `matrix_parent_inverse` — при копировании иерархий верните его, иначе дети «улетают».
- В macOS нет `timeout`; долгий процесс запускай в фоне и опрашивай.
