# MeshGate

> Asset gateway: one export from **Blender / Maya** → the web and the **Unity, Godot, Unreal** game engines.

Documentation is available in English and Russian — every page has a language switcher at the top.

**Start here → [Getting started](docs/getting-started.md):** what to install, how to connect an AI, and what to know
for the web, Unity, Godot and Unreal.

MeshGate is a toolkit that brings a 3D asset from a DCC editor to a single normalized **glTF/GLB** under a strict "asset contract", and then delivers it to any runtime: the browser (Three.js) and game engines. The architecture is "hub and spokes": the canonical GLB sits in the center, surrounded by swappable source and target adapters. Adding a new editor or engine = adding an adapter, without touching the core.

This is a standalone tool (all code is ours; proprietary, see [License](#license)). The pipeline idea (DCC → glTF → runtime) is an industry standard; the implementation is original.

## Why

- One asset — everywhere: make it in Blender or Maya, get a working load in the web and in three engines.
- Predictability: the "asset contract" (scale, axes, materials, names) eliminates "mine is rotated/huge/black".
- Verifiability: the validator catches problems before the asset reaches the engine.

## Interchange format

The core is **glTF 2.0 (.glb)**: the common denominator for the web and real-time (native in Blender, native import in Godot/Unreal, Unity via glTFast, Web via Three.js). For heavy rigs/scenes and Maya-originated assets there is a fallback path via FBX/USD (see `docs/architecture.md`).

## In Blender: the add-on (no terminal needed)

Install it with one command — `python3 meshgate.py install-blender` (close Blender first) — or by hand from `meshgate-blender-<version>.zip`: Blender 4.2+ — drag the zip into the window; Blender 3.5–4.1 — Preferences → Add-ons → Install. Then **N → MeshGate**: tick the targets, press **Check**, **Fix all**, **Export**. It writes a validated GLB plus FBX, `UCX_` collision for Unreal, `-convcolonly` collision for Godot and `_LOD` meshes for Unity, and opens the result in the browser. Tested on Blender 3.5, 4.2 LTS and 5.2 LTS — see [sources/blender/README.md](sources/blender/README.md).

## Quick start (Blender → Web end-to-end run)

```bash
# 0. Without exporting anything — view a ready-made example:
python3 targets/web/serve.py            # http://localhost:8770/targets/web/ → samples/meshgate_demo.glb

# 1. Export your own asset from Blender per the contract (headless) + validate right away:
blender -b your.blend -P sources/blender/export_meshgate.py -- --out samples/asset.glb --validate
#    flags: --draco (geometry compression), --fbx (plus FBX for the Unity/Unreal editor), --no-animations, --selection, --image-format WEBP

# 2. Standalone validation against the contract (stdlib, suitable for CI):
python3 core/validate_glb.py samples/asset.glb            # --strict: warnings = errors, --json: for machines

# 3. Viewing:
python3 targets/web/serve.py --glb samples/asset.glb
```

Examples in `samples/` — the "crate with a beacon", a lantern (glass, emission), a barrel (normal map), a drone (hierarchy, rotors) and the rigged character `meshgate_hero` (Unity Humanoid skeleton, UVs, bone animations); for your own character — `sources/blender/animate_humanoid.py`. The crate: hierarchy, a hinged lid, two animations, PBR textures, emission, glass, a Draco variant. It is also the test for all target adapters. Web viewer: hover/click/focus on objects, a tree, animations with a timeline, HDRI, shadows, Draco/KTX2/meshopt, drag-and-drop of your own files — see [targets/web/README.md](targets/web/README.md).

## Generate from a description or a picture

- **Text → 3D:** `python3 meshgate.py gen "a wooden windmill with turning sails"` asks your AI command-line tool
  (Claude Code, Codex, Gemini, Ollama or any other) for a short `build(mg)` function on MeshGate's modeling kit. It
  builds the model once per quality tier and sends problems back to the AI until the build is clean.
- **Picture → 3D:** `python3 meshgate.py gen --image photo.jpg` runs a neural generator. That is TripoSR on your own
  machine (MIT, set up with one command) or Meshy, Tripo, TRELLIS or Hunyuan3D in the cloud. MeshGate then stands the
  mesh upright, decimates it per tier, unwraps it and bakes its colour and normals.
- **Any mesh:** `--mesh file.glb` brings a downloaded model to the contract the same way.

## MeshGate Studio: the desktop app

[MeshGate Studio](apps/studio/README.md) puts generation in a window for macOS and Windows: a description, a style, the
tiers, then a 3D view of each tier, the progress of every attempt and a library of everything you made. Run it without
installing anything with `python3 meshgate.py studio`, or build the Tauri app (about 6 MB).

![MeshGate Studio](docs/img/studio.png)

## Quality tiers: mobile low / mid / high and PC

Budgets and render settings for four device tiers live in [`core/profiles.json`](core/profiles.json): the validator checks files against them (`--profile all`), the Blender add-on exports `<name>.<tier>.glb` within budget, and the web viewer, Unity, Godot and Unreal pick the tier's files and rendering (PC: soft shadows, AO, bloom). Details — [docs/quality-tiers.md](docs/quality-tiers.md).

## One command: `meshgate.py`

```bash
python3 meshgate.py doctor                                   # which tools were found (Blender, Unity, Godot)
python3 meshgate.py export scene.blend --out build/asset.glb --fbx   # contract export + validation
python3 meshgate.py character avatar.glb --out build/hero.glb        # rigged humanoid → contract (+ idle/wave)
python3 meshgate.py validate build/asset.glb build/asset.fbx --strict
python3 meshgate.py serve --glb build/asset.glb              # web viewer
python3 meshgate.py samples                                  # rebuild every demo asset from its Blender script
python3 meshgate.py check all                                # web + Unity + Godot checks, headless
python3 meshgate.py gen "a cast-iron fire hydrant" --size 0.8   # text → asset per quality tier through an AI CLI
python3 meshgate.py studio                                   # MeshGate Studio in the browser
```

Tool paths are discovered automatically; override with `MESHGATE_BLENDER`, `MESHGATE_UNITY`, `MESHGATE_GODOT`.

## Agent skill

[`SKILL.md`](SKILL.md) turns the pipeline into a repeatable skill for an AI coding agent (Claude Code, Codex): classify the input → prepare in Blender → export → map every validator warning to a fix → deliver to web/Unity/Godot/Unreal → verify headless → report. Install it with `python3 scripts/install_skill.py` (`--codex` for Codex).

## Target engines

| Target | How | Status |
|---|---|---|
| Web | `targets/web` — the `meshgate-viewer.js` library + a demo page on Three.js | done (v0.2) |
| Unity 6 | `targets/unity` — UPM package `com.meshgate.unity` on top of Unity glTFast, sample project, PlayMode tests; FBX as a fallback path for the editor | done (v0.3) |

## Structure

```
meshgate.py     the CLI: doctor, export, character, validate, serve, samples, check, gen, studio
SKILL.md        agent skill (+ SKILL.ru.md), scripts/install_skill.py installs it
core/           asset contract + GLB and FBX validators (our code, stdlib)
sources/blender Blender add-on (check · fix · export, 3.5–5.x), modeling kit, headless export, demo generators
sources/generate text/picture → asset: prompt, AI CLI adapters, guard rails, neural mesh generators, refine, examples
apps/studio     MeshGate Studio: local server + UI, Tauri desktop shell for macOS and Windows
sources/maya    paths from Maya (FBX→glTF / USD / plugin)
samples/        demo asset: .blend, .glb, .draco.glb
targets/web     viewer library meshgate-viewer.js + demo page (Three.js, MIT)
targets/unity   UPM package on top of Unity glTFast + sample project with PlayMode tests
targets/godot   meshgate addon + demo project + headless check
targets/unreal  MeshGate plugin (editor Python scripts) + recipes
docs/           asset contract, architecture, vision, roadmap
.github/        CI: validation of the samples against the contract (--strict)
```

## Status

v0.6.2. Generation works from a description (kit code by any AI CLI) and from a picture (TripoSR locally, or Meshy,
Tripo, TRELLIS, Hunyuan3D), with one validated file per quality tier; MeshGate Studio wraps it in a desktop app for
macOS and Windows. The Blender add-on is ready for everyone (Blender
3.5, 4.2 LTS and 5.2 LTS tested). Web, Unity and Godot share the same API and automated contract checks; Unreal is
checked against its Python API without the engine. Generated assets go through the same engine checks as the hand-built
samples. Next — a live Unreal run, Maya, public releases; characters and PBR map transfer later. Roadmap — `docs/roadmap.md`.
