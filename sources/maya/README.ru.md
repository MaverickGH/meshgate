# Источник: Maya

В Maya нет экспорта glTF «из коробки», поэтому к каноническому GLB ведут три пути.
Цель одна — получить GLB по [контракту ассета](../../docs/asset-contract.ru.md).

## Путь A — плагин glTF (рекомендуется для веба)
- **Maya2glTF** или **Babylon.js Exporter for Maya** (оба открытые). Ставится как плагин Maya, экспортирует прямо в GLB.
- Перед экспортом: рабочие единицы — метры, применить историю/заморозить трансформы, материалы Standard Surface (переносятся в PBR).

## Путь B — через FBX (когда важны риги/анимации в движках)
- Maya экспортирует FBX нативно (`File → Export`).
- Конвертация FBX → GLB: `FBX2glTF` (открытый CLI) или импорт FBX в Blender и экспорт нашим `sources/blender/export_meshgate.py`.

## Путь C — через USD (большие сцены, студийный пайплайн)
- Maya нативно пишет USD (`mayaUsd`). Для веба USD не подходит; для Unreal/Unity — нативно/через пакеты.

## Проверка
Любой полученный GLB прогнать через `python3 core/validate_glb.py asset.glb`.

> Автоматизация (MEL/Python-скрипт экспорта Maya→GLB по контракту) — в роадмапе v0.3.
