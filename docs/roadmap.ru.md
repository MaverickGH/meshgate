# Роадмап MeshGate

## v0.1 — каркас (сделано)
- [x] Ядро: контракт ассета + валидатор GLB (stdlib).
- [x] Источник Blender: экспорт в GLB по контракту (headless).
- [x] Цель Web: вьюер на Three.js + локальный сервер.
- [x] Стартеры Unity/Godot/Unreal/Maya + документация.

## v0.2 — Web до эталона (сделано)
- [x] Реальный демо-ассет: генератор `.blend` (сундук с маяком), экспорт в GLB и Draco-GLB, всё в `samples/`.
- [x] Экспортёр: анимации, apply scale, Draco-уровень, формат текстур, `--validate` сразу после экспорта.
- [x] Валидатор: мировые габариты в метрах, UV/нормали, неприменённые трансформы, степени двойки у текстур, имена, расширения по целям, `--strict`/`--json`, CI.
- [x] Вьюер-библиотека `meshgate-viewer.js`: hover/click/фокус, анимации с таймлайном, RoomEnvironment/HDRI, тени, Draco/KTX2/meshopt, drag-and-drop.
- [x] Демо-страница как референс метода: паспорт ассета, дерево объектов, анимации, вид, загрузка своих файлов.
- [ ] Отложено: локальная копия Three.js для офлайна; сравнение «до/после» Draco в UI.

## v0.3 — Unity (сделано)
- [x] UPM-пакет `com.meshgate.unity` поверх Unity glTFast 6.20: `MeshGateAsset` (рантайм-загрузка, имена, анимации, коллайдеры), `MeshGateInteraction`, `MeshGateOrbitCamera`, меню валидации.
- [x] Sample-проект (Unity 6000.0): демо-сцена «импорт редактором + рантайм», HUD, headless-сборка `BuildAll`.
- [x] PlayMode-тесты как спецификация контракта в Unity: иерархия/имена, масштаб 1, метры/Y-up, origin, клипы, открытие крышки, рендер в PNG.
- [x] FBX как запасной путь: `--fbx` в экспортёре (Unity/Unreal-настройки, take на стрип, встроенные текстуры), `core/validate_fbx.py`, постпроцессор материалов `MeshGateFbxMaterials`, FBX в демо-сцене и сверка FBX↔GLB в `BuildAll`.
- [x] Персонажи: демо-гуманоид `meshgate_hero` (скелет Unity Humanoid, веса, UV, `idle`/`wave`), `animate_humanoid.py` для чужих ригов (Mixamo/Rigify/UE), валидатор скинов/весов/Humanoid, скелет и UV-шахматка во вьюере, Humanoid-аватар и Mecanim-ретаргет в Unity, поддержка нового Input System, сборка демо-сцены как меню пакета.
- [ ] Отложено: Draco/KTX2 через `com.unity.cloud.draco`/`ktx`; Unity CI (нужна лицензия в GitHub Actions); roughness-карта для FBX (запечь в альфу metallic-карты).

## v0.4 — Godot и пропсы (сделано)
- [x] Пропсы: фонарь (transmission/ior/эмиссия, `swing`/`flicker`), бочка (normal- и roughness-карты), дрон (иерархия, `hover`/`rotors`); галерея примеров во вьюере, пропсы в Unity-сцене и тестах.
- [x] Godot 4: аддон `meshgate` (MeshGateAsset / OrbitCamera / Interaction / Hud), демо-проект, `tests/test_meshgate.gd` (headless, все 5 ассетов), `screenshot.gd`; снимок `docs/img/godot-demo.png`.
- [x] LOD и прокси коллизий из экспортёра (`_LODn` для Unity, `UCX_` для Unreal, `-convcolonly` для Godot) — в аддоне Blender v0.5.
- [ ] Отложено: Draco в Godot через GDExtension.

## v0.4.1 — Unreal
- [x] Плагин переписан под Interchange (пайплайн MeshGate, UCX-коллизии, bind-поза, анимации) с запасным старым FBX-импортом; повторяемый демо-уровень со светом; валидатор на Python редактора.
- [x] `tests/unreal/check_api.py` — каждое имя Unreal, которое использует плагин, сверяется со стабами Python API UE 5.4/5.5/5.6, в CI.
- [ ] Первый живой прогон в UE 5.5/5.6; C++ `MeshGateAsset` на glTFRuntime.

## v0.5 — Аддон Blender для всех (сделано)
- [x] Аддон (legacy 3.5–4.1 и extension 4.2+ из одного zip): панель с целями, проверка с кнопкой исправления у каждой проблемы, «Исправить всё», экспорт с отчётом валидатора, превью в браузере, прокси коллизий, LOD, русский интерфейс.
- [x] Правила контракта внутри Blender с исправлениями: единицы, размер, масштаб, имена (транслитерация), UV, материалы, текстуры (упаковка, степень двойки), пол, переименование костей в Humanoid (Mixamo/UE/Rigify), веса, NLA.
- [x] Один код для панели и CLI (`export_meshgate.py --check --fix --targets`); `compat.py` для изменений API Blender 3.5 → 5.x; генераторы демо работают на 3.5, 4.2 LTS, 5.2 LTS.
- [x] `meshgate.py check blender`: подкладывает в сцену все проблемы, проверяет Check/Fix/Export и варианты для движков на каждом найденном Blender, пересобирает демо-ассеты; CI гоняет его на Blender 4.2 LTS.

## v0.5.1 — Пример пака «Коты-зомби» (сделано)
- [x] 11 стилизованных ассетов + диорама из одного скрипта: материал-палитра, варианты с коллизиями, кот-зомби на Humanoid (idle/shamble), диорама из связанных дубликатов; одинаковый результат на Blender 3.5, 4.2 LTS и 5.2 LTS.
- [x] Проверено насквозь: проверка контракта и экспорт в аддоне, валидатор, группа в веб-галерее, сцена пака в Unity (+ Humanoid-ретаргет клипа кота на героя), тест пака в Godot (включая коллизии `-convcolonly` через редакторский импорт), `import_pack` в Unreal по стабам API.
- [x] Найдено и исправлено по пути: Blender сбрасывает `matrix_parent_inverse` при присваивании `.parent` (дети в диораме «улетали»); вариант для Godot терял прокси при экспорте выделенного; слишком сильная эмиссия после тонмаппинга.

## v0.5.2 — Уровни качества (сделано)
- [x] `core/profiles.json`: mobile-low / mobile-mid / mobile-high / pc — бюджеты ассета и сцены, настройки рендера; `tests/check_profiles.py` держит копии в web/Unity/Godot/Unreal одинаковыми (CI).
- [x] Валидатор: draw calls, память текстур, кости на скин, влияния на вершину; `--profile`, `--scene`, `fits`.
- [x] Blender: варианты уровней в пределах бюджета (децимация до арматуры, уменьшение текстур, влияния, JPEG), переключатели в панели, `--profiles`; генератор пака строит каждый уровень со своей детализацией (`--detail/--tiers`), канон = PC.
- [x] Рантайм: автоопределение в вебе + `setQuality` + загрузка вариантов + пост-обработка на PC (GTAO, HDR-bloom); `MeshGateQuality` в Unity и Godot + выбор варианта; `apply_quality` + `import_pack(profile=)` в Unreal.
- [x] Три сцены улицы котов-зомби (Low / Mid / PC) в тестовых проектах Unity и Godot, с рендером в тестах.

## v0.6 — Генерация по тексту и MeshGate Studio (сделано)
- [x] `meshgate.py gen`: описание → код `build(mg)` через любой ИИ-CLI (Claude Code, Codex, Gemini, Ollama, своя команда), ограждения, сборка в Blender под каждый уровень качества («детализация по необходимости»), проверка, цикл исправлений — `docs/generation.ru.md`.
- [x] Набор для моделирования `meshgate_blender/modeling.py`: примитивы, тела вращения, трубы, выдавливание, зеркало, объединение, шарниры, анимация; один материал-палитра (цвет + шероховатость/металличность + свечение) на ассет = один draw call на любом уровне.
- [x] MeshGate Studio: локальный сервер + интерфейс (`meshgate.py studio`) и оболочка Tauri для macOS и Windows, установщики собираются в CI — `apps/studio/README.ru.md`.
- [x] Веб-вьюер: выборочный bloom (светится только свечение материалов).
- [x] Проверено: одного промпта хватило на фонарь и мельницу, собравшиеся с первой попытки; подставной ИИ-CLI гоняет цикл исправлений на каждой версии Blender в `check blender` и в CI.

## v0.6.1 — Картинка → 3D и нейросетевой текст → 3D (сделано)
- [x] Движок mesh: TripoSR локально (MIT, установка одной командой, Apple MPS / CUDA / CPU) и Meshy, Tripo, fal (TRELLIS, Hunyuan3D, TripoSR) в облаке или любая своя команда; текст → картинка через OpenAI или FLUX для генераторов по картинке.
- [x] `refine.py`: любая сгенерированная или скачанная сетка → контракт по уровням — нормализация, выпрямление (самое широкое плоское основание), чистка, упрощение до доли уровня, развёртка, запекание цвета и нормалей (Cycles), экспорт и проверка; `gen --mesh`.
- [x] Картинки для движка kit: ИИ-CLI видит картинку (у Claude только инструмент Read, Codex -i, Gemini @file).
- [x] Studio: загрузка картинки, выбор движка и генератора, установка TripoSR в один клик.
- [x] Проверено: TripoSR вживую на M4 Pro; наклонённая тестовая сетка через доводку на Blender 3.5/4.2/5.2 и в CI; облачные адаптеры на подставном сервере.
