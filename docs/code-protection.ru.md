# Упаковка кода MeshGate

Репозиторий остаётся публичным. Оригиналы пяти ключевых модулей Studio
заменены на загрузчики и нативные пакеты `native/studio/` для трёх платформ.
Исходники этих модулей сохранены только в локальной ветке разработки.
Остальной опубликованный код по-прежнему можно копировать. Нативные библиотеки
тоже можно анализировать; компиляция повышает стоимость такого анализа.
`AGENTS.md` напоминает AI-инструментам об условиях лицензии; это не контроль доступа.

## Что входит в сборки 0.6.11

В нативные библиотеки `.so` / `.pyd` компилируются `meshgate.py`, сервер Studio,
генерация, отправка моделей в движки и установка дополнительных компонентов.
В дистрибутиве на их месте остаются небольшие загрузчики; исходная реализация
этих пяти модулей, сгенерированный C и отладочные файлы не поставляются.
Оригиналы этих пяти файлов в публичном снимке отсутствуют.

Studio использует собственный CPython 3.11.16. Для Windows x64, macOS ARM64 и
Linux x64 собираются отдельные пакеты. Нужный интерпретатор и uv поставляются
вместе с приложением. Подмена runtime системным Python для нативной сборки
не поддерживается: ABI должны совпадать.

Код Blender, GLB/FBX-валидаторы, примеры, плагины и прочие вспомогательные
модули остаются Python/JavaScript-кодом для работы в разных версиях движков.
Отдельный экспериментальный нативный пакет валидаторов доступен через
`build_native_core.py` без `--studio`, но не применяется к Blender.

## Собрать и проверить

Нужны Python с pip и компилятор C: Xcode Command Line Tools, MSVC Build Tools
или системный компилятор Linux. В локальной ветке разработки Cython 3.3.0 и setuptools 84.0.0 устанавливаются
в отдельный build-venv. Публичная сборка использует готовые проверяемые пакеты
и не требует компилятора C.

```bash
python3 scripts/vendor_three.py
python3 scripts/prepare_studio_bundle.py
python3 scripts/make_portable.py --compiled --out dist --keep out/native-portable
python3 tests/studio/test_bundle.py out/native-portable --private-runtime --blender /path/to/blender
```

На Windows замените `python3` на `python`. Desktop-сборка запускает подготовку
автоматически через `npm run build` в `apps/studio/desktop`.
Исходный checkout не изменяется; промежуточные файлы остаются в игнорируемых
`out/`, `dist/` и `apps/studio/desktop/runtime/`.

Portable: Windows — `START_WINDOWS.cmd`; macOS/Linux — `sh START.sh`.
Для CLI используйте включённый Python:
`runtime/studio/python/bin/python3.11 meshgate.py doctor` на macOS/Linux или
`runtime\studio\python\python.exe meshgate.py doctor` на Windows.

CI проверяет загрузчики вместо исходников, старт сервера без системного Python,
статус инструментов, просмотрщик без сети и построение промпта. Linux дополнительно
проверяет генерацию kit-модели и обработку сетки в Blender до создания релиза.

## История и лицензирование

Публичная история сброшена в корневой снимок 0.6.11 с библиотеками.
Локальные исходники и история сохранены отдельно. Новые изменения снова
создают обычную историю: Git нужен для разработки. Старые теги и релизы удалены;
локальная резервная копия хранится вне репозитория. Существующие копии и кэши
GitHub очистка не отзывает. Она не меняет лицензию ранее полученных версий.

Активация через Supabase пока не реализована: для подключения нужны выбранный
проект, схема выдачи лицензий и параметры доступа. Secret/service-role ключи
нельзя помещать в приложение, публичный Git или JavaScript сайта.

Рекомендации для других проектов: [чеклист и готовый запрос](code-protection-other-repos.ru.md).

## Разработка и публикация

Локальная ветка `local-development` содержит исходники. Не отправляйте её
на публичный origin. Обычный `git push` в рабочем checkout отключён.
Публичный `main` содержит загрузчики и библиотеки. Для новой версии сначала
из локальных исходников соберите все три нативных пакета, проверьте реальные
операции, обновите ZIP и SHA-256 в публичном снимке и только затем публикуйте
новый релиз. Не восстанавливайте реализацию защищаемых модулей в публичном Git.

Для запуска клона используйте включаемый runtime: сначала
`python3 scripts/build_studio_runtime.py`, затем
`apps/studio/desktop/runtime/studio/python/bin/python3.11 meshgate.py studio`.
На Windows используйте `python.exe` вместо `bin/python3.11`.
