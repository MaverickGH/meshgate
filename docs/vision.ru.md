# Видение MeshGate

Цель — повторяемый, управляемый агентом пайплайн, который доводит 3D-ассет
до «движко-готового» состояния и доставляет в любой рантайм. Как навык-скилл:
дал вход → получил проверенный ассет в вебе и в движках, без ручного цикла
«экспортнул — в движке кривой масштаб/нет развёртки — переэкспортнул».

## Входы: меши можно делать по-разному
1. **По описанию (text → 3D).** Из текстового промпта генерируется черновая геометрия (открытые модели вроде TripoSR/InstantMesh или внешний API), дальше — доводка по контракту.
2. **По картинке (image → 3D).** Из референс-изображения восстанавливается меш.
3. **Готовая модель.** Уже сделанный ассет из Blender/Maya приводится к контракту.

Любой вход сводится к одному нормализованному GLB.

## Движко-готовность (что нужно движкам)
Ассет проходит доводку под требования движков:
- **UV-развёртка** (unwrap) — без неё не лягут текстуры;
- вменяемая **топология** (чистые нормали, без вывернутых граней, разумный полигонаж);
- **масштаб/оси** по контракту (метры, Y-up);
- **PBR-материалы**;
- **LOD**-уровни для дальних планов;
- **коллизии** (упрощённый меш столкновений);
- понятные **имена** объектов/материалов.

Валидатор ловит нарушения до попадания в движок.

## Доставка
Один канонический GLB → web (Three.js), Unity (glTFast), Godot (native), Unreal (native/Interchange). Запасной путь FBX/USD для риг/больших сцен. Источники: Blender и Maya.

## Почему это сильно помогает геймдеву
Самое дорогое в конвейере ассетов — не моделинг, а доводка и переносы между
инструментами и движками. MeshGate снимает эту рутину: генерация или импорт →
автодоводка под контракт → предсказуемая загрузка в любой движок и в веб.

## Порядок работ
Сначала доводим **web** до эталона, затем **Unity**, потом **Godot/Unreal**,
затем генерация мешей (описание/картинка + движко-доводка), и в конце — **Maya**
как второй источник.
