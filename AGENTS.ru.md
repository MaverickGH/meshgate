## Упаковка

`scripts/build_native_core.py` собирает нативные валидаторы либо оркестрацию
Studio с `--studio`. `scripts/prepare_studio_bundle.py` включает фиксированный
CPython. Код Blender и его валидаторы остаются Python для совместимости.
Исходный checkout не меняется; сборочные файлы не коммитьте.

Нативные библиотеки требуют совпадения ОС, архитектуры и ABI Python.
Запускайте Studio её включённым интерпретатором и проверяйте генерацию через
Blender до публикации релиза.
